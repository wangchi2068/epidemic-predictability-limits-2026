\noindent{\heiti\bfseries 摘要：}【目的】传染病前瞻预测在多周外推与流行峰邻近期普遍出现技能骤降与区间欠覆盖。本文旨在厘清机制方差、参数不确定性与实测误差三者的数理关联，给出可核验的机制基准，并进一步判别峰前校准失效主要源于离散度设定偏误还是均值模型误设。【方法】建立平方损失下的条件风险恒等式；对固定离散度周度负二项（NB2）聚合更新模型推导精确有限步方差闭式，相对方差含几何发散主项 $[(1+1/k_{\text{agg}})^h-1]$；以对数正态放大律刻画参数外推误差；在条件正交假定下以阈值方程定义机制预测视界。实证依托三组微观传播链、覆盖最多 51 个州级辖区的多病原住院面板（七个流行阶段）与 CDC FluSight 三个锁定赛季的版本化审计，并对机制预测器实施位置--宽度分解诊断。【结果】微观数据支持负二项相对 Poisson 的过度离散设定（$\Delta\text{AIC}$ 93.9--244.0）；5 周基准窗口下州级机制视界中位数 2.2--7.1 周（跨州自助 95\% 区间 1.2--9.7 周），推断窗口在 5/6/8/10 周间变动带来 $-48.8\%$ 至 $+44.5\%$ 的同量级敏感性，故点值不作精确解读；21 个阶段--步长配置的模型--观测代数差额占比中位数 55.0\%，机制分量不足以覆盖实测误差；FluSight 审计中机制预测器在全部相位欠覆盖（全季 0.405--0.554），Hub 集成峰后期覆盖率 0.925--0.964 而峰前期降至 0.419--0.852。分解诊断表明：峰前失效以\textbf{位置偏差}为主导——峰前单元中 $91.7\%\text{--}100\%$ 被模型低估（中位相对误差 $-0.45$、$-0.60$、$-0.78$），峰后则相反（仅 $9.8\%\text{--}44.4\%$ 低估，v1.1.0 中位误差 $+1.08$）；将离散度参数 $k_{\text{agg}}$ 放宽至 $1/512$ 仍无法使 v1.1.0 与 v1.2.0 峰前覆盖率恢复至 0.90 以上（曲线峰值 0.872 与 0.744，而同季 v1.0.0 可达 0.954），而叠加整体位置缩放后可达 0.991 与 0.971（v1.0.0/v1.1.0，样本量 108/343；v1.2.0 峰前仅 43 个单元，其数值在正文作方向性参考）。【结论】机制视界是依赖工作模型与信息集的条件基准，其与实测时效的关系是分布性而非逐点成立的（294 个逐州配对单元中 $21.1\%$ 反号）；峰前校准差距的可归因来源主要是均值模型在转折期的系统性方向偏差，而非静态离散度设定偏误。

\section{引言}\label{sec:intro}

\subsection{研究背景与现实困境}

重大呼吸道传染病（如新型冠状病毒感染、季节性流感与呼吸道合胞病毒 RSV）的周期性暴发对全球公共卫生与医疗体系构成长期挑战。在疫情早期的动态演化中，及时可靠的前瞻预测是优化重症资源配置、预置抗病毒药物与启动非药物干预（NPI）的关键支撑。然而，传染病前瞻预测在实务中频繁遭遇系统性失效瓶颈：当疫情处于平稳指数增长或下降阶段时，现有统计与动力学模型通常能保持较高准确度；但一旦逼近流行阈值（即基本再生数 $R \approx 1$ 的临界点）或开展多周前瞻外推，预测系统的性能便发生系统性劣化：预测区间急剧发散、预测轨迹频繁出现预测性能骤降与严重失准\citep{reich2019collaborative}。Scarpino 与 Petri\citep{scarpino2019predictability} 基于信息论与排列熵刻画了疫情在流行阈值附近的无模型内在可预测性突变；然而，无模型排列熵界主要反映时间序列本身的统计可压缩性，未显式给出特定生成机制下有限步前瞻方差的累积律与参数推断误差的传播闭式。

为应对前瞻预测的重大现实需求，计算流行病学形成了动力学房室模型、统计更新模型、机器学习与多模型集成四大范式。然而，跨越多年与多病种的大规模协同预测评估揭示了长期制约前瞻预测实践的结构性瓶颈。无论是美国 CDC FluSight 流感预测\citep{mcgowan2019collaborative, flusight2024evaluation}、RAPIDD 埃博拉评估\citep{viboud2018rapidd}、登革热预测挑战\citep{johansson2019open}，还是欧美 COVID-19 预测枢纽\citep{cramer2022evaluation, sherratt2023europeanhubs}，评估结果均表明：在多周前瞻外推（3--4 周及以上）或波次起伏临界期，绝大多数复杂流行病学模型的实测预测技巧均迅速衰减，甚至难以稳定优于简单的持续性基线或局部线性外推模型\citep{suez2026baseline, lopez2024challenges}。此外，早期监测数据普遍存在的报告延迟与漏报回填，使得远期外推面临严重的使用不可识别性\citep{melikechi2022limits, king2015avoidable}。

\subsection{本文定位与核心贡献}\label{sec:contrib}

针对上述空白，本文的定位是\textbf{构建并校准一个机制基准，并用它判别峰前校准失效的来源}，而非提出新的预测模型。核心贡献有四：

\begin{enumerate}
\item \textbf{组织基准层面}：以平方损失下的条件风险恒等式（定理~\ref{thm:sharp_floor}）作为全部分析的分层基准。它给出条件均值预测器在给定概率模型与信息集下达到的锐条件方差下界，并因此说明：任何“预测视界”概念都必然依赖预测规则、归一化方式与容忍阈值的选择，不存在与工作模型无关的绝对视界。
\item \textbf{理论层面}：对固定离散度 $k_{\text{agg}}$ 的周度 NB2 聚合更新模型，给出任意有限步条件方差的显式裂项闭式（定理~\ref{thm:macro_exact}），相对方差中含几何发散主项 $[(1+1/k_{\text{agg}})^h-1]$；并以对数正态放大律（引理~\ref{lem:param_amplification}）刻画参数外推误差。需要明确的是，负二项自回归监测模型族（hhh4 类）的既有工作已通过均值--方差递推解析传播多步二阶矩\citep{held2005statistical, held2017monitoring, bracher2022endemic}；本文在该脉络上的增量是：对齐性常参数周度更新这一最简情形，递推可裂项求和为\textbf{不依赖逐步迭代的显式闭式}，使几何发散项在相对方差中显式可见，并可直接逆解视界阈值方程（定理~\ref{thm:horizon}）。
\item \textbf{实证校准层面}：微观传播链证实负二项相对 Poisson 的过度离散优势（$\Delta\text{AIC}$ 达 93.9--244.0，属相对拟合命题）；在覆盖全美最多 51 个州级辖区的多病原住院面板上，5 周基准窗口下测得机制视界跨州中位数 2.2--7.1 周（跨州自助 95\% 区间 1.2--9.7 周；推断窗口变动带来与阶段间差异同量级的敏感性，见表~\ref{tab:window_nb}）；描述性误差记账表明两个显式机制分量平均仅解释约 45\% 的实测相对误差。
\item \textbf{失效来源判别层面（本文新的核心发现）}：在 CDC FluSight 三个锁定赛季的严格四方配对单元上，对机制预测器实施\textbf{位置--宽度分解诊断}，把峰前欠覆盖归因于两个可分离的候选来源。结果表明失效以\textbf{位置偏差为主导}：峰前单元中 $91.7\%\text{--}100\%$ 被模型低估（三季中位相对误差 $-0.45$、$-0.60$、$-0.78$），峰后则系统性转为高估（v1.1.0 中位误差 $+1.08$），符号结构跨三季一致；同时，将离散度参数 $k_{\text{agg}}$ 放宽至 $1/512$ 仍无法使 v1.1.0 与 v1.2.0 的峰前覆盖率恢复至 0.90 以上（曲线峰值 0.872 与 0.744，而同季 v1.0.0 可达 0.954），而一个整体位置缩放即可做到。据此，本文将“静态方差设定偏误”从峰前击穿的主要可归因来源中\textbf{降级}为次要来源，而把均值模型在流行转折期的系统性方向偏差提升为主要来源（第~\ref{sec:phase_collapse} 节）。
\end{enumerate}

\section{研究回顾}\label{sec:review}

\textbf{第一，分支过程、更新模型与多步矩演化。}Galton--Watson 负二项分支过程\citep{athreya1972branching}与更新方程为刻画个体超扩散提供了经典的统计似然基础\citep{lloyd-smith2005superspreading}。在群体推断层面，Cori 等\citep{cori2013framework}与 Gostic 等\citep{gostic2020practical}确立了时变再生数 $R_t$ 的贝叶斯滤波推断规范；Parag 等\citep{parag2020information, parag2022fundamental, parag2022quantifying}进一步从信息论视角揭示了发病曲线反演再生数所固有的代间隔检测延迟与信息瓶颈。在计数监测序列的统计建模方向，Held 等\citep{held2005statistical}建立了负二项自回归的 hhh 建模结构，经 hhh4 及其概率预测扩展\citep{held2017monitoring}与离散代间隔传播形式\citep{bracher2022endemic}发展成型。必须强调：这一模型族在多步前瞻时\textbf{已通过均值--方差递推解析传播二阶矩，并不依赖蒙特卡洛仿真}，本文不在此点上主张首创。本文的增量定位为：对齐性常参数周度更新 NB2 这一最简情形，将递推裂项求和为显式闭式（定理~\ref{thm:macro_exact}），使几何发散结构在相对方差中闭式可见，并可直接逆解视界阈值方程；对含协变量、季节项与邻接结构的 hhh4 一般情形，此类闭式不再成立。此外，强过离散小样本下负二项离散度参数极大似然估计的下偏\citep{lloyd-smith2007fisher}，以及传播链规模分布对 $R$ 与 $k$ 的可辨识性约束\citep{blumberg2013inference}，共同界定了微观层推断的解释边界。

\textbf{第二，预测视界的概念界定与生态学先例。}Petchey 等\citep{petchey2015ecological}将“生态预测视界”（ecological forecast horizon）形式化定义为预测误差首次达到预设容忍度门槛的时间距离，并强调视界是依赖系统内在动力学、外生扰动、模型规则与损失函数的操作系统构造；Wesselkamp 等\citep{wesselkamp2025forecast}进一步辨析了确定性非线性系统与随机生灭过程在可预测时间尺度上的本质差异。Castro 等\citep{castro2020turning}证明扩张流行波的转折点与终点在机制上不可精确预测；Penn 等\citep{penn2023intrinsic}区分了模型内在随机性与统计认知不确定性。在实证尺度上，Bozzuto 与 Ives\citep{bozzuto2023differences}在全美州县尺度测得 COVID-19 时间序列的无模型可预测跨度至多约 8--9 周。该结果与本文机制视界（跨州中位数 2.2--7.1 周、多窗口包络 1.52--8.07 周）在尺度上相容，但对象不同：前者是不依赖模型的统计可预测性度量，本文是给定 NB2 工作模型与推断规则下的模型内条件基准，二者不可直接互换（第~\ref{sec:hub_audit} 节给出对照讨论）。

\textbf{第三，概率预测评估与校准。}严格适当评分规则\citep{gneiting2007strictly}、区间格式的加权区间评分（WIS）\citep{bracher2021evaluating}与计数数据的随机化 PIT\citep{czado2009predictive}构成概率预测评估的方法学基线；Bosse 等\citep{bosse2023scoring}讨论了跨规模辖区聚合评分时绝对尺度 WIS 被大辖区主导的风险，本文因此在国家级与州级口径间保持区分。多赛季评估反复报告上升期欠覆盖与区间偏窄\citep{mcgowan2019collaborative, flusight2024evaluation, cramer2022evaluation}；White 与 Le\'on\citep{white2026forecastability}进一步证明部分季节与病原本身就系统性更难预测，这构成本文峰前期现象的一个重要竞争性解释（第~\ref{sec:phase_collapse} 节）。现有评估多针对业务模型的经验对比，缺乏剥离外生工程修饰的受控机制基准；本文以版本锁定的枢纽审计补足这一对照，并将结论限定为描述性证据。

\section{传播动力学可预测视界理论}\label{sec:theory}

\subsection{锐条件平方风险下界与尺度隔离原则}\label{sec:risk_floor}

考虑离散时间下的周度宏观发病与住院监测序列 $\{Z_t\}_{t \ge 0}$。预测原点 $t$ 历史信息集构成 $\sigma$-代数流 $\mathcal{F}_t = \sigma(Z_0, Z_1, \dots, Z_t; \mathbf{X}_t)$。预测目标为超前提前期 $h \ge 1$ 步的真实状态变量 $Y_{t+h}$（终报口径下 $Y_{t+h} = Z_{t+h}$）。定义预测规则类为 $\mathcal{D}_t \equiv L^2(\Omega, \mathcal{F}_t, \mathbb{P})$。记条件期望与条件方差分别为：
\begin{equation}
m_h \equiv \mathbb{E}[Y_{t+h} \mid \mathcal{F}_t], \qquad V_h \equiv \operatorname{Var}(Y_{t+h} \mid \mathcal{F}_t).
\end{equation}

\begin{theorem}[\textbf{条件风险恒等式与锐条件方差下界}]\label{thm:sharp_floor}
对于任意预测规则 $\delta_h \in \mathcal{D}_t$，平方损失下的条件预测风险恒成立严格代数正交分解：
\begin{equation}
\mathcal{R}_h(\delta_h \mid \mathcal{F}_t) \equiv \mathbb{E}\left[(Y_{t+h} - \delta_h)^2 \;\middle|\; \mathcal{F}_t\right] = V_h + \bigl(m_h - \delta_h\bigr)^2. \label{eq:sharp_floor_identity}
\end{equation}
由此，条件均值预测器 $\delta_h^\star = m_h$ 在 $L^2$ 空间几乎处处（$\mathbb{P}$-a.s.）是唯一达到最小条件风险的最优预测器，其达到的下限恰为系统的不可约方差下界：$\inf_{\delta \in \mathcal{D}_t} \mathcal{R}_h(\delta \mid \mathcal{F}_t) = V_h$。任何经验预测器的超额风险严格非负且等于其平方偏差 $(m_h - \delta_h)^2 \ge 0$。
\end{theorem}

\begin{lemma}[\textbf{微观 Galton--Watson 分支过程的两阶矩递推}]\label{lem:branch_moments}
设个体子代分布满足期望 $\mathbb{E}[\xi]=R$，方差 $\operatorname{Var}(\xi)=\sigma^2 = R + R^2/k_{\text{ind}}$。预测原点初始感染人数 $Z_0 = I_0$。则第 $h$ 代累计发病规模的均值与方差满足严格解析递推：
\begin{equation}
\mathbb{E}[Z_h] = I_0 R^h, \qquad \operatorname{Var}(Z_h) = \begin{cases} I_0 \sigma^2 R^{h-1} \dfrac{R^h - 1}{R - 1}, & R \neq 1, \\[6pt] I_0 h \sigma^2, & R = 1. \end{cases} \label{eq:lem1_var}
\end{equation}
\end{lemma}

\begin{lemma}[\textbf{微观相对方差饱和界与信息可达性}]\label{lem:cv_floor}
在超临界传播（$R > 1$）下，个体分支过程的相对方差（变异系数平方 $\text{CV}^2_{\text{micro}}(h)$）随提前期 $h$ 单调递增并有界饱和于饱和常数界：
\begin{equation}
\text{CV}^2_{\text{micro}}(h) = \frac{\operatorname{Var}(Z_h)}{(\mathbb{E}[Z_h])^2} = \frac{(1 + R/k_{\text{ind}})(1 - R^{-h})}{I_0(R - 1)} \;\xrightarrow{h \to \infty}\; \text{CV}^2_\infty \equiv \frac{1 + R/k_{\text{ind}}}{I_0(R - 1)}. \label{eq:cv_floor}
\end{equation}
\end{lemma}

\subsection{宏观负二项更新模型的精确有限步方差闭式与机理边界}\label{sec:macro_model}

在周度宏观监测尺度上，疾病传播序列在离散时间步下满足条件负二项更新分布 $Z_t \mid \mathcal{F}_{t-1} \sim \text{NB}(R_{\text{周}} Z_{t-1}, k_{\text{agg}})$。记周度乘子 $R \equiv R_{\text{周}}$，初始发病水平 $Z_0 = I_0$。从连续代间隔分布的经典卷积更新方程向周度离散模型过渡时，该更新结构对应于代间隔时间分布的粗粒化点质量近似，其相对卷积更新方程的截断误差未在本文量化，属于模型设定层面的近似（第~\ref{sec:limitations} 节）。同时，本模型采用固定离散度 NB2 结构（条件方差包含均值平方项 $\mu^2 / k_{\text{agg}}$），与宏观准泊松（方差呈线性放大的 NB1 结构）在方差累积动力学上存在本质差异：NB1 在超临界下相对方差渐近收敛饱和，而 NB2 结构内生导致几何发散项 $[(1 + 1/k_{\text{agg}})^h - 1]$。本文将这一结构视为\textbf{工作模型设定}而非普适物理定律，其经验合理性由第~\ref{sec:empirical} 节的相对拟合证据与第~\ref{sec:hub_audit} 节的校准审计共同界定。

\begin{theorem}[\textbf{固定离散度宏观负二项更新模型的精确有限步方差闭式}]\label{thm:macro_exact}
在逐代独立更新的宏观负二项（NB2）聚合模型下，条件方差满足一阶差分递推 $V_{t+1} = q V_t + I_0 R^{t+1} + \frac{I_0^2 R^{2t+2}}{k_{\text{agg}}}$，其中 $q \equiv R^2 (1 + 1/k_{\text{agg}})$。对于任意整数提前期 $h \ge 1$，该递推方程具有精确有限步方差闭式解：
\begin{equation}
V_h = I_0 R\, \frac{q^h - R^h}{q - R} + I_0^2 \left(q^h - R^{2h}\right), \label{eq:macro_var_closed}
\end{equation}
其相对均方误差（变异系数平方 $\text{CV}^2_{\text{macro}}(h)$）严格等于：
\begin{equation}
\text{CV}^2_{\text{macro}}(h) \equiv \frac{V_h}{(I_0 R^h)^2} = \frac{R}{I_0}\cdot\frac{q^h - R^h}{R^{2h}(q - R)} + \left[\left(1 + \frac{1}{k_{\text{agg}}}\right)^{\!h} - 1\right]. \label{eq:macro_cv2_closed}
\end{equation}
\end{theorem}

\begin{remark}\label{rem:degenerate}
式~\eqref{eq:macro_var_closed} 的分母 $q - R$ 在 $q = R$ 时为零，由 $q = R \Leftrightarrow R = k_{\text{agg}}/(k_{\text{agg}}+1) < 1$ 可知该退化仅发生于亚临界域，在本文关注的超临界域 $R > 1$ 内不出现；$R = 1$ 的临界分支由引理~\ref{lem:branch_moments} 的对应情形按连续性处理。
\end{remark}

\begin{lemma}[\textbf{参数不确定性的对数正态放大律}]\label{lem:param_amplification}
设参数点估计满足大样本渐近正态性 $\log\hat{R} \sim \mathcal{N}(\log R, s^2)$。采用自然代入式点预测 $\hat{Z}_h = I_0 \hat{R}^h$，由对数正态矩展开，参数外推误差导致的相对均方误差贡献项 $P_{\text{exact}}(h)$ 具有严格解析闭式：
\begin{equation}
P_{\text{exact}}(h; s) \equiv \frac{\mathbb{E}[(I_0 \hat{R}^h - I_0 R^h)^2]}{(I_0 R^h)^2} = \exp(2 h^2 s^2) - 2\exp(\tfrac{1}{2} h^2 s^2) + 1. \label{eq:param_amplification}
\end{equation}
其领先阶二次项展开为 $P_{\text{quad}}(h; s) = (h s)^2$。
\end{lemma}

\begin{remark}\label{rem:plugin_bias}
代入式点预测本身系统性上偏：$\mathbb{E}[\hat{Z}_h] = I_0 R^h \exp(h^2 s^2/2) > m_h$。引理~\ref{lem:param_amplification} 的 $P_{\text{exact}}$ 已将该偏差计入平方误差贡献，推导无歧义；但定理~\ref{thm:fisher} 的 Cram\'er--Rao 界以 $\hat{R}$ 无偏为前提，两者口径不同，不可混用。
\end{remark}

\subsection{条件正交假定、辨识信息界与机制预测视界映射}\label{sec:horizon_theory}

将过程方差项与参数放大项合并为总相对均方误差，需要一个可检验的加性条件。

\begin{assumption}[\textbf{条件正交}]\label{assump:orthog}
设参数估计 $\hat{R}_t$ 为 $\mathcal{F}_t$-可测，代入式预测器 $\hat{\delta}_h = I_0 \hat{R}_t^{\,h}$。定义归一化交叉项
\begin{equation}
C_h \equiv \frac{\mathbb{E}\left[(Y_{t+h} - m_h)\,(m_h - \hat{\delta}_h) \mid \mathcal{F}_t\right]}{m_h^2}.
\label{eq:cross_term}
\end{equation}
假定~\ref{assump:orthog} 即 $C_h = 0$，其充分条件是参数估计误差与未来过程噪声在 $\mathcal{F}_t$ 条件下不相关。
\end{assumption}

该假定在有限样本下一般\textbf{不严格成立}：$\hat{R}_t$ 由包含起点 $Z_t$ 的同一窗口估计，增长更快的窗口倾向于高估 $\hat{R}$，从而产生正向相关偏向。本文不以该假定为精确断言，而是在第~\ref{sec:simulation} 节以蒙特卡洛量化其量级：在与表~\ref{tab:horizons} 参数量级一致的三组配置下，$|C_h|$ 不超过过程方差项的 $0.6\%$，加性分解在该尺度下近似有效。

\begin{theorem}[\textbf{负二项似然下的 Fisher 信息量与 Cram\'er--Rao 识别下限}]\label{thm:fisher}
设子代计数 $X_1,\dots,X_N$ 独立同分布服从 $\text{NB}(R, k_{\text{ind}})$。在 $(R, k_{\text{ind}})$ 双参数化下，每观测 Fisher 信息阵为对角阵：$I_{RR} = k_{\text{ind}}/(R(R+k_{\text{ind}}))$，$I_{Rk}=0$。因此即使 $k_{\text{ind}}$ 未知、与 $R$ 联合估计，$R$ 的 Cram\'er--Rao 界仍为 $\operatorname{Var}(\hat{R}) \ge R(R+k_{\text{ind}})/(N k_{\text{ind}})$；单侧检验下使估计相对标准误低于 $\varepsilon$ 的理想有效样本量门槛为 $N \gtrsim (1 + R/k_{\text{ind}})\,\varepsilon^{-2} = O(\varepsilon^{-2})$。
\end{theorem}

\begin{theorem}[\textbf{机制预测视界映射}]\label{thm:horizon}
在假定~\ref{assump:orthog} 下，预测总相对均方误差加性分解为
\begin{equation}
\text{RelMSE}(h) = \text{CV}^2_{\text{macro}}(h) + P_{\text{exact}}(h;s_{\text{周}}).
\label{eq:relmse_additive}
\end{equation}
在超临界域 $R>1$ 且 $s_{\text{周}}>0$ 时，$\text{RelMSE}(h)$ 关于 $h$ 严格单调递增、连续，且 $\text{RelMSE}(0)=0$、$\text{RelMSE}(h)\to\infty$，故对任意 $\tau \in (0,1)$，机制预测视界
\begin{equation}
h^*_{\text{cont}} \equiv \sup\left\{h \ge 0 \;\middle|\; \text{RelMSE}(h) \le \tau^2\right\} \label{eq:h_star_def}
\end{equation}
为 $\text{RelMSE}(h) = \tau^2$ 的唯一根，且 $h^*$ 关于 $s_{\text{周}}$ 严格单调递减。进一步，将几何发散项一阶线性化（$[(1+1/k_{\text{agg}})^h - 1] \approx h/k_{\text{agg}}$）、略去亚主导的首项与 $P_{\text{exact}}$ 的高阶项，阈值方程化为二次方程 $s_{\text{周}}^2 h^2 + h/k_{\text{agg}} = \tau^2$，其正根给出线性化闭式速算：
\begin{equation}
h^* \approx \frac{\sqrt{b^2 + 4 s_{\text{周}}^2 \tau^2} - b}{2 s_{\text{周}}^2}, \qquad b \equiv \frac{1}{k_{\text{agg}}}. \label{eq:h_star_closed}
\end{equation}
\end{theorem}

\begin{remark}\label{rem:approx_accuracy}
式~\eqref{eq:h_star_closed} 仅为速算工具：在表~\ref{tab:horizons} 七个阶段的中位参数下，它相对精确根系统性高估 $8\%$--$29\%$（中位约 $10\%$）。相比之下，仅保留参数项的领先阶近似 $h \approx \tau/s_{\text{周}}$ 在同一组参数下高估 $1.70$--$2.94$ 倍（中位 $2.08$），原因是精确根处几何发散项已占 $\tau^2$ 的 $58.0\%$--$83.0\%$（七阶段跨州中位数，见附录~A 末），不可忽略。因此本文全部 $h^*$ 数值均以式~\eqref{eq:h_star_def} 的数值求根为准。
\end{remark}

\subsection{非对称损失下的分位数最优预报与视界--损失联合依赖}

定理~\ref{thm:horizon} 的视界定义在平方损失上，其最优预报为条件均值。公共卫生决策很少用平方损失：低估疫情峰值引发医疗挤兑的代价与同等幅度高估导致过度备勤的沉没成本并不相等。本节把视界扩展到分段二次非对称损失，得到本文的第二个理论结果。

\begin{definition}[分段二次非对称损失]\label{def:asym_loss}
设 $a \in (0,1)$ 为低估权重，定义
\begin{equation}
L_a(y, d) \;=\; a\,(y-d)^2\,\mathbb{1}\{y > d\} \;+\; (1-a)\,(d-y)^2\,\mathbb{1}\{y \le d\}.
\end{equation}
$a = 1/2$ 时退化为平方损失；$a \to 1$ 时几乎只惩罚低估（疫情预警的典型取向）。
\end{definition}

\begin{theorem}[非对称损失下的分位数最优预报与视界--损失联合]\label{thm:asym}
设预测目标 $Y_{t+h}$ 的条件分布函数 $F_h$ 连续且严格递增，则在损失 $L_a$ 下：
\begin{enumerate}[label=(\roman*)]
\item \textbf{最优预报是 $a$-分位数}：$\delta_h^\star(a) = F_h^{-1}(a)$ 是式
\begin{equation}
\inf_{d}\,\mathbb{E}\!\left[L_a(Y_{t+h}, d)\mid \mathcal{F}_t\right]
\end{equation}
的唯一解；$a=1/2$ 时即条件中位数，与平方损失下的条件均值在分布对称时重合。
\item \textbf{风险相对平方损失严格不减}：记 $\mathcal{R}^{\text{sq}}_h = V_h$（定理~\ref{thm:sharp_floor}），则
\begin{equation}
\mathcal{R}^{a}_h \;\ge\; \mathcal{R}^{\text{sq}}_h,\qquad
\mathcal{R}^{a}_h - \mathcal{R}^{\text{sq}}_h \;=\; a(1-a)\,\mathbb{E}\!\left[\bigl|Y_{t+h} - m_h\bigr|\,\bigm|\, \mathcal{F}_t\right]^2 \ge 0,
\end{equation}
当且仅当分布退化为单点时取等。
\item \textbf{视界依赖损失权重}：以相对均方根误差容忍度 $\tau$ 定义视界，则 $h^*(a)$ 关于 $a$ 的漂移在工作点处满足
\begin{equation}
\frac{\partial h^*}{\partial a}\Bigg|_{\tau} \;=\; -\,\frac{\partial_{\!a}\,\text{RelMSE}(h;a)}{\partial_{\!h}\,\text{RelMSE}(h;a)} \;<\;0 \quad (a > 1/2),
\end{equation}
即低估权重越大，可用视界越短；且在工作点 $\text{RelMSE}(h^*) \approx \tau^2$ 且预测律近正态时，其一阶量级为
\begin{equation}
\left|\frac{\partial h^*}{\partial a}\right|_{\tau} \;\approx\; \frac{\tau}{2\,s_{\text{周}}\sqrt{1+\text{CV}^2_{\text{tot}}(h^*)}}\cdot\frac{1}{\phi\!\left(\Phi^{-1}(a)\right)},
\end{equation}
其中 $\phi,\Phi$ 为标准正态密度与分布函数，$\text{CV}^2_{\text{tot}}$ 为式~\eqref{eq:relmse_additive} 的总相对方差。
\end{enumerate}
\end{theorem}

\begin{proof}[定理~\ref{thm:asym} 的证明]
(i) 条件期望下对 $d$ 逐点求导（$F_h$ 连续严格递增保证可换序）：$\partial_d\,\mathbb{E}[L_a(Y,d)\mid\mathcal{F}_t] = -2a\,\mathbb{E}[(Y-d)^+\mid\mathcal{F}_t] + 2(1-a)\,\mathbb{E}[(d-Y)^+\mid\mathcal{F}_t]$。由恒等式 $\mathbb{E}[(Y-d)^+] = \int_d^\infty (1-F_h(y))\,dy$ 与 $\mathbb{E}[(d-Y)^+] = \int_{-\infty}^d F_h(y)\,dy$，令导数为零得 $a\int_d^\infty (1-F_h) = (1-a)\int_{-\infty}^d F_h$，即 $F_h(d) = a$。二阶导数 $2[aF_h(d) + (1-a)(1-F_h(d))] = 2a(1-a) > 0$，故为唯一极小点。
(ii) 平方损失下最优为 $m_h$、风险为 $V_h$；在 $L_a$ 下以 $m_h$ 为预报点代入并关于 $a$ 求导可得增量项 $a(1-a)\,\mathbb{E}[|Y-m_h|\mid\mathcal{F}_t]^2$，非负且仅在 $Y=m_h$ a.s. 时为零。
(iii) 视界定义为隐函数 $\text{RelMSE}(h^*(a),a)=\tau^2$，对 $a$ 求导即得第一式；在工作点以正态近似 $F_h^{-1}(a) \approx m_h + \sigma_h\Phi^{-1}(a)$、$\sigma_h^2 = \text{CV}^2_{\text{tot}} m_h^2$，代入 $\partial_a\,\text{RelMSE} = -2\Phi^{-1}(a)\sigma_h/(m_h^2\phi(\Phi^{-1}(a)))$ 与 $\partial_h\,\text{RelMSE} \approx 2 s_{\text{周}}^2 h^*/m_h^2$，并用 $h^*\approx\tau/s_{\text{周}}$ 得第二式。
\end{proof}

该定理对第~\ref{sec:phase_collapse} 节的实证发现给出直接解释：若公共卫生决策本质上要求 $a \gg 1/2$（低估代价远高于高估），则按中位数口径构造的机制预测器在峰前\textbf{必然}系统性低估——这不是方差设定偏误，而是预报点选在错误分位数上的后果。第~\ref{sec:phase_collapse} 节表~\ref{tab:location_width} 与第~\ref{sec:operational} 节给出该 $a$ 的实测标定。

本节对理论结果做三层检验；全部脚本与随机数种子随代码仓库发布（附录声明），主检验脚本为 \texttt{scripts\_v2/verify\_journal\_claims.py}（种子 20260921）。

\textbf{（一）代数恒等检验。}在 $R \in [0.5, 3.0]$、$k_{\text{agg}} \in [0.1, 50]$、$I_0 \in [10, 1000]$、$h \in \{1,\dots,12\}$ 的宽网格上随机抽取 $10^4$ 组参数，逐步递推与定理~\ref{thm:macro_exact} 闭式的最大相对偏差不超过 $5 \times 10^{-14}$，确认闭式与递推在代数上恒等。

记账结果（表~\ref{tab:budget_four}）如下：在全部 21 个阶段--步长配置中，代数差额跨州中位占比的中位数为 \textbf{55.0\%}（$h=1$ 为 45.3\%，$h=4$ 升至 78.6\%）；21 个配置中 \textbf{20 个}的跨州中位差额为正。须同时指出唯一的中位数为零配置：JN.1 的 $h=1$（跨州中位 $0.0\%$，四分位距 $[-36.1, 18.2]$，差额为正的州占比仅 $49\%$——即抛硬币水平），因此「20/21 为正」不应读作强结论；末列显示其余配置为正的州占比介于 54\% 与 94\% 之间，其中 RSV 2025--26 的三个配置（69\%/58\%/54\%）与 RSV 2024--25 的 $h=1$（74\%）同样接近临界。必须按定义如实解读：$\mathcal{E}_{\text{res}}$ 是算术余项，恒有定义，吸收模型误设、非平稳漂移、行为适应、报告回填以及两个显式项自身的估计误差。因此该记账是\textbf{描述性构成分析而非因果正交分解}：它与「显式机制分量不足以覆盖实测误差」的定性结论一致，但不支持任何更强的因果断言，尤其不支持把 $\mathcal{E}_{\text{res}}$ 解释为某个可命名的物理成分。这一事实与「理论机制视界应定位为基于动力学生成假设的诊断性经验参照，其与实测时效的关系是分布性而非逐点成立的」这一定位相互印证。

\textbf{（3）位置--宽度分解诊断：峰前失效以位置偏差为主导。}机制预测器享有终报数据质量优势，仅剥离了初报--回填噪声；其区间宽度由 $k_{\text{agg}}$ 的 NB2 方差闭式决定，而第~\ref{sec:flusight_scores} 节已测得其区间比基线窄 12.6\%--44.6\%。要把“欠覆盖”归因到具体来源，须先区分两种性质不同的失配：\textbf{位置失配}（预测分布的中位数偏离真值）与\textbf{宽度失配}（中位数正确但离散度不足）。此前的反事实宽度补偿诊断只问了“要多大宽度才达标”，未问“宽度是否是瓶颈”，故不足以支撑归因。本文补做三项检查（表~\ref{tab:location_width}）。

其一，\textbf{位置偏差的符号结构}。逐单元计算预测中位数相对真值的相对误差 $(\tilde q_{11} - Y)/Y$：峰前单元中 $91.7\%$（v1.0.0）、$93.9\%$（v1.1.0）与 $100\%$（v1.2.0）被\textbf{低估}，中位相对误差为 $-0.451$、$-0.602$、$-0.782$；峰后则系统性反向，被低估比例降至 $44.4\%$、$9.8\%$、$28.4\%$，中位误差转为 $+0.094$、$+1.078$、$+.434$。即模型\textbf{系统性低估上升速度、高估下降速度}，且该符号结构在三个独立赛季上完全一致——这是转折期均值模型误设的特征，而非抽样噪声。

其二，\textbf{宽度单独能否修复}。将每个单元的 $k_{\text{agg}}$ 在 $[1, 1/512]$ 的网格上统一缩放（等价于把区间从已发表口径逐步放到极宽），重算 95\% 覆盖率（表~\ref{tab:location_width} 与图~\ref{fig:location_width}）。该曲线\textbf{非单调}：覆盖率随放宽上升，到达峰值后回落——因为区间放到极宽时下限被压至 0、上限超出真值可能范围，反而开始漏失。峰值位置与峰值高度分相位为：峰后 $0.948/0.970/0.944$（v1.0.0/v1.1.0/v1.2.0，下同）、峰值 $1.000/0.962/0.969$、峰前 $0.954/0.872/0.744$。即\textbf{v1.0.0 的全部相位都能靠放宽离散度恢复标称}，而 v1.1.0 与 v1.2.0 的峰前相位\textbf{最好只到 0.872 与 0.744}，均无法达到 0.90。同时，峰前相位的 50\% 覆盖率在全部缩放档位上接近零（v1.2.0 恒为 0.000）——中位数预测几乎从不落在真值附近。一个中心点偏离数倍的分布，放宽离散度无法救回。

其三，\textbf{位置修正的增益远大于放宽离散度}。作为上界诊断，取每单元真值与预测中位数之比的中位数作为整体缩放因子（此为 oracle 量，用于估计“位置修好就够”的上界，不是可部署规则），峰前缩放因子为 $1.82$、$2.52$、$4.59$（三季均 $>1$ 且递增），峰后为 $0.91$、$0.48$、$0.70$（三季均 $<1$）。在缩放与 $k$ 联合最优处，峰前覆盖率由单纯放宽 $k$ 的 $0.954$/$0.872$/$0.744$ 提升至 $0.991$/$0.971$/$1.000$，峰后亦由 $0.948$/$0.970$/$0.944$ 提升至 $0.942$/$0.975$/$0.930$（表~\ref{tab:location_width}）。位置修正是必要条件，放宽宽度不是。

据此，本文对峰前期校准差距的归因作出\textbf{降级与重排}：静态离散度设定偏误虽是真实存在的宽度量级事实（区间系统性偏窄 12.6\%--44.6\%，且峰前所需宽度补偿 2.5--6.1 倍大于峰后 2.1--2.2 倍），但分解诊断表明它\textbf{不是}峰前击穿的主要可归因来源；主要来源是均值模型 $I_0 R^h$ 在流行转折期的系统性方向偏差。仍保留的竞争性解释是部分季节与病原的固有难度\citep{white2026forecastability}与终报真值在峰前的向上回填修订——本诊断不能将其量化分离。须同时声明：本文的 oracle 位置缩放证明“位置修好就足以恢复覆盖”，但不证明“位置修好就能做到”；一个可部署的相位敏感均值模型能否在样本外复现该增益，是本文未完成的后续工作。

观测侧的对照支持“外包络”定位：各州滚动原点下，代入式外推误差与持续性基线误差之比首次穿越 1 的中位周数为 1.0--4.3 周，相当于同阶段机制视界的 0.20--1.27 倍——多数阶段观测技能视界短于机制视界，两个流感阶段反向（1.10--1.27 倍），与 NB2 几何发散项在该参数域偏保守的方向一致（对照表~\ref{tab:window_nb} 中 NB1/Poisson 口径下视界延长 1.06--2.56 倍）。

从数学极限向应急运筹转化，首先要回答的不是“视界有多长”，而是“按什么损失报告视界”。定理~\ref{thm:asym} 指出：视界依赖损失权重 $a$，且 $a>1/2$ 时可用视界严格短于中位口径。把这一依赖量化到公卫决策上有三个可直接使用的推论。

其一，\textbf{同一机制视界在不同决策下不等价}。在表~\ref{tab:horizons} 七个阶段的中位工作点上直接求解 $h^*(a)$（$\tau=0.5$，重解式~\eqref{eq:h_star_def} 的同一阈值方程、仅把预报点由中位数换成 $a$-分位数，数值根见附录~A 末）：$a=0.5$ 时视界为 $2.16\text{--}7.68$ 周；转到 $a=0.75$ 收缩至 $1.56\text{--}5.91$ 周；转到 $a=0.9$ 进一步收缩至 $0.90\text{--}3.71$ 周；$a=0.95$ 时仅余 $0.65\text{--}2.80$ 周。即从中位口径转到强低估规避口径，视界收缩 $1.3\text{--}4.0$ 周，为其原值的 $52\%\text{--}59\%$。这与重症 ICU 扩容通常需要 1--2 周前置准备的刚性需求叠加后，意味着在 $\tau=0.20$ 档（实测视界 $0.40\text{--}1.48$ 周）下，按中位口径调度的决策在强低估规避口径下几乎不剩有效预警窗口。这不是模型缺陷，而是用错误分位数做决策的必然代价。

其二，\textbf{最优决策形式是预置冗余而非点预测}。定理~\ref{thm:asym}(i) 表明最优预报为 $F_h^{-1}(a)$；当 $a\to1$ 时该预报点趋向预测分布的上尾，其本身即是“最坏极端情景鲁棒防御”的数理形式。因此决策者不应把中位轨迹当作调度基准，而应按目标 $a$ 取预测分布的相应分位数设定床位与物资冗余；相应地，\textbf{有效预警提前量应改写为} $\Delta t_{\text{alert}} = h^*(a) - t_{\text{detect}}$，即净预警窗口同时受视界的损失依赖与检测延迟压缩，需通过高灵敏度前哨监测点压缩 $t_{\text{detect}}$。

其三，\textbf{$a$ 可由审计数据标定，无需主观指定}。把每个评估单元的终报真值代入机制预测器的预测分布，得到隐含损失权重 $\alpha_{\text{cell}} = F_{\text{pred}}(Y)$。三季实测（表~\ref{tab:asym_calibration}）：峰前 $\alpha$ 中位数为 $0.993$、$0.997$、$1.000$，峰后为 $0.387$、$0.007$、$0.175$——即若要使机制预测器的点预报最优，峰前需取接近分布上界的分位数，峰后则需取下侧分位数。这与 FluSight 审计自身的 WIS 惩罚结构一致：v1.2.0 的欠预测惩罚 $56.55$ 对过预测惩罚 $39.27$，隐含 $a = 56.55/(56.55+39.27) \approx 0.59$，处于表~\ref{tab:asym_calibration} 峰前与峰后之间，无需调参即与理论相容。这为“为什么按中位数口径构造的预测器在峰前必然低估”提供了独立于方差设定的解释。

在健康公平性层面，定理~\ref{thm:horizon} 给出 $h^*$ 关于 $s_{\text{周}}$ 严格单调递减：监测网络稀疏地区的 $s_{\text{周}}$ 预期更大，机制视界相应缩短。但必须明确本文数据能支持到哪里：全部 51 个辖区的 $s_{\text{周}}$ 与 $I_0$ 均在终报口径的同一套住院面板上估计，未引入报告率或漏报协变量，也未做任何「降低报告率后重估参数」的反事实，故「报告率下降会抬高 $s_{\text{周}}$ 并压低 $I_0$，从而压缩视界」这一方向性预期\textbf{没有本文数据支撑}，本文不对其幅度作任何量化声明。作为本文框架内唯一可执行的 $I_0$ 重定标，把 $I_0$ 由 5 周窗口均值改为窗口末值或回归拟合端点，跨州中位 $h^*$ 的变动仅 $-0.2\%$ 至 $+4.8\%$（七阶段逐值见附录~A 末），说明 $I_0$ 的口径选择本身不是视界的敏感来源；报告率变化如何经由 $s_{\text{周}}$ 传导，需要以含报告率协变量的受控研究单独回答。相应地，本节不向「监测薄弱地区视界大幅塌缩」的方向外推，仅保留定理~\ref{thm:horizon} 的单调性结论与「资源配置应向监测薄弱地区倾斜常态化网络建设」的方向性建议——后者的依据是 $s_{\text{周}}$ 变小在任何参数设定下都不使视界变长，而非本文测得的某个具体塌缩幅度。

\subsection{研究局限性}\label{sec:limitations}

本文的适用边界体现在七个方面。(1) \textbf{模型内量}：机制视界由“假定 NB2 为真、5 周窗口估参、再代回同一 NB2 方差闭式求根”得到，属模型内条件量，不存在与工作模型无关的估计对象；方差口径切换（NB1/Poisson）使视界延长 1.06--2.56 倍，窗口切换带来 $-48.8\%$ 至 $+44.6\%$ 变动（表~\ref{tab:window_nb}）。(2) \textbf{固定离散度与峰前期现象的张力}：$k_{\text{agg}}$ 在窗口内固定，而第~\ref{sec:phase_collapse} 节的分解诊断表明峰前失效以位置偏差为主导、宽度不是瓶颈，故时变离散度\textbf{不是}恢复峰前校准的主要方向；真正待答的是均值模型在转折期的系统性方向偏差。新增两条边界：(i)~\textbf{分布性而非逐点成立}：294 个逐州配对单元中 $21.1\%$ 的机制视界短于实测时效，其中流感 2022--23 与 RSV 2025--26 的反号比例达 $31.6\%$ 与 $38.5\%$，故本文不将机制视界表述为外包络，只表述为约五分之四单元上同向的诊断性参照；(ii)~\textbf{oracle 位置缩放是上界诊断}：它证明位置修好即足以恢复覆盖，但不证明位置修好就能做到；可部署的相位敏感均值模型能否在样本外复现该增益，是本文未完成的后续工作。(3) \textbf{事后分层}：峰前/峰后标签依赖季末全局峰值，不可实时构造；$\pm 7$ 天阈值为约定。(4) \textbf{外部效度}：三个赛季、单一国家，不支撑跨病原、跨体制的普适结论。(5) \textbf{推断纪律}：覆盖率检验经 Bonferroni 校正，其余多重比较均为描述性；代数差额为算术余项。(6) \textbf{理论近似}：周度离散更新相对连续卷积更新的截断误差未量化；理论未耦合易感耗竭非线性负反馈（SIR 类），适用于流行早期上升阶段。

\section{结论}\label{sec:conclusion}

本文构建了以条件风险恒等式为组织基准、以固定离散度 NB2 更新模型的显式方差闭式为核心机制、以阈值方程为输出接口的预测视界体系，并以微观传播链、州级面板与版本化枢纽审计做了三层校准。可核对的主要结论有五：其一，固定 $k_{\text{agg}}$ 的 NB2 结构在超临界域产生相对方差的几何发散主项，闭式与逐步递推在代数上恒等（第~\ref{sec:simulation} 节）；其二，机制视界是模型内条件量，跨窗口与跨方差口径的敏感性与阶段间差异同量级（窗口变动 $-48.8\%$ 至 $+44.5\%$），故应以 5 周基准区间 2.2--7.1 周连同跨州自助区间 1.2--9.7 周报告，并附口径敏感性，而不以任何单一窗口的点值报告；其三，两个显式机制分量平均仅解释约 45\% 的实测相对误差，其余由模型误设与非平稳成分吸收；其四，FluSight 审计中机制预测器全相位欠覆盖（全季 0.405--0.554），且其与实测时效的关系是分布性的——294 个逐州配对单元中 $78.9\%$ 同向、$21.1\%$ 反号，故不构成逐点外包络；其五，也是本文的新发现，\textbf{峰前校准失效以位置偏差为主导}：峰前单元 $91.7\%$\text{--}$100\%$ 被低估而峰后系统性转为高估（符号结构跨三季一致），且把 $k_{\text{agg}}$ 放宽至 $1/512$ 仍不能使 v1.1.0/v1.2.0 峰前覆盖率过 0.90（曲线峰值 0.872/0.744，同季 v1.0.0 可达 0.954），而位置缩放可以——据此本文将静态方差设定偏误从峰前击穿的主要可归因来源中降级。

本文未能回答的问题同样明确：一个可部署的相位敏感均值模型能否在\textbf{样本外}复现 oracle 位置缩放所指示的增益，需要以前两季估形式、第三季不调参验证的留出实验；三个赛季、单一国家的证据外推边界如何，需要跨病原、跨体制的扩展审计；相位分层规则的在线化（例如基于实时增长率符号的构造）尚待实现。机制视界作为同口径下的诊断性经验参照，为公共卫生应急调度提供了统计可信窗口的保守边界，也为下一代把方差设定与均值动态同时作为一等公民的预测系统标定了改进方向。

\begin{proof}[定理~\ref{thm:sharp_floor} 的证明]
对任意 $\delta_h \in \mathcal{D}_t$，逐点展开
$(Y_{t+h}-\delta_h)^2 = (Y_{t+h}-m_h)^2 + 2(Y_{t+h}-m_h)(m_h-\delta_h) + (m_h-\delta_h)^2$。
取条件期望：第一项即为 $V_h$；交叉项中 $m_h - \delta_h$ 为 $\mathcal{F}_t$-可测并可提出，而 $\mathbb{E}[Y_{t+h}-m_h \mid \mathcal{F}_t] = 0$，故交叉项条件期望为零；第三项 $\mathcal{F}_t$-可测，其条件期望等于自身。于是得式~\eqref{eq:sharp_floor_identity}。又 $(m_h-\delta_h)^2 \ge 0$ 且几乎处处为零当且仅当 $\delta_h = m_h$ a.s.，故下确界在 $\delta_h^\star = m_h$ 处唯一达到且等于 $V_h$。
\end{proof}

\begin{proof}[引理~\ref{lem:branch_moments} 的证明]
以 $\{Z_{h-1}=z\}$ 为条件，$Z_h = \sum_{i=1}^{z}\xi_i^{(h)}$ 为 $z$ 个独立同分布子代数之和，故 $\mathbb{E}[Z_h \mid Z_{h-1}=z] = Rz$，$\operatorname{Var}(Z_h \mid Z_{h-1}=z) = \sigma^2 z$。均值满足 $\mathbb{E}[Z_h] = R\,\mathbb{E}[Z_{h-1}]$，$Z_0=I_0$，迭代得 $I_0 R^h$。方差由全方差公式
$v_h \equiv \operatorname{Var}(Z_h) = \sigma^2 \mathbb{E}[Z_{h-1}] + R^2 v_{h-1} = \sigma^2 I_0 R^{h-1} + R^2 v_{h-1}$，$v_0 = 0$。
对 $R \ne 1$ 展开几何求和：$v_h = \sigma^2 I_0 \sum_{j=0}^{h-1} R^{2(h-1-j)} R^{j} = \sigma^2 I_0 R^{h-1} (R^h - 1)/(R-1)$；$R=1$ 时 $v_h = h \sigma^2 I_0$。
\end{proof}

\begin{proof}[引理~\ref{lem:cv_floor} 的证明]
将式~\eqref{eq:lem1_var} 的方差除以 $(I_0 R^h)^2$ 并代入 $\sigma^2 = R(1+R/k_{\text{ind}})$：
\begin{align*}
\operatorname{Var}(Z_h)/(\mathbb{E}Z_h)^2 &= \sigma^2 R^{h-1}(R^h-1)\big/\bigl((R-1)I_0 R^{2h}\bigr) \\
&= (1+R/k_{\text{ind}})(1-R^{-h})\big/\bigl(I_0(R-1)\bigr).
\end{align*}
右端关于 $h$ 单调递增（$1 - R^{-h}$ 递增）且有界，极限为 $(1+R/k_{\text{ind}})/(I_0(R-1))$。
\end{proof}

\begin{proof}[定理~\ref{thm:macro_exact} 的证明]
NB2 更新给出一阶与二阶条件矩：$\mathbb{E}[Z_{t+1}\mid\mathcal{F}_t] = R Z_t$，$\operatorname{Var}(Z_{t+1}\mid\mathcal{F}_t) = R Z_t + (R Z_t)^2/k_{\text{agg}}$。由全方差公式并用归纳假设 $\mathbb{E}[Z_t] = I_0 R^t$、$\mathbb{E}[Z_t^2] = V_t + I_0^2 R^{2t}$：
\[
V_{t+1} = \mathbb{E}\bigl[R Z_t + R^2 Z_t^2/k_{\text{agg}}\bigr] + R^2 V_t
= \Bigl(R^2 + \tfrac{R^2}{k_{\text{agg}}}\Bigr) V_t + I_0 R^{t+1} + \tfrac{I_0^2 R^{2t+2}}{k_{\text{agg}}},
\]
即 $V_{t+1} = q V_t + I_0 R^{t+1} + I_0^2 R^{2t+2}/k_{\text{agg}}$，$q = R^2(1+1/k_{\text{agg}})$，$V_0=0$。解此一阶线性差分方程：
\[
V_h = \sum_{j=0}^{h-1} q^{\,h-1-j}\Bigl(I_0 R^{j+1} + \tfrac{I_0^2 R^{2j+2}}{k_{\text{agg}}}\Bigr)
= I_0 R\,\frac{q^h - R^h}{q - R} + \frac{I_0^2 R^2}{k_{\text{agg}}}\cdot\frac{q^h - R^{2h}}{q - R^2}.
\]
由 $q - R^2 = R^2/k_{\text{agg}}$，第二项化简为 $I_0^2 (q^h - R^{2h})$，得式~\eqref{eq:macro_var_closed}。对其除以 $(I_0 R^h)^2$：第一项为 $\frac{R}{I_0}\cdot\frac{(q/R^2)^h - R^{-h}}{q-R}$，而 $q/R^2 = 1+1/k_{\text{agg}}$；第二项为 $q^h/R^{2h} - 1 = (1+1/k_{\text{agg}})^h - 1$，即式~\eqref{eq:macro_cv2_closed}。退化情形见注~\ref{rem:degenerate}。
\end{proof}

\begin{proof}[引理~\ref{lem:param_amplification} 的证明]
$\log\hat R \sim \mathcal{N}(\log R, s^2)$ 时 $\hat R^h$ 服从对数正态分布，其一二阶矩为 $\mathbb{E}[\hat R^h] = R^h e^{h^2 s^2/2}$、$\mathbb{E}[\hat R^{2h}] = R^{2h} e^{2h^2 s^2}$。于是
$\mathbb{E}[(\hat R^h - R^h)^2] = R^{2h}\bigl(e^{2h^2s^2} - 2e^{h^2s^2/2} + 1\bigr)$，除以 $(I_0 R^h)^2 \cdot I_0^{-2}$ 得式~\eqref{eq:param_amplification}。对 $x = h^2 s^2$ 作泰勒展开 $e^{2x} - 2e^{x/2} + 1 = x + O(x^2)$，领先阶为 $(hs)^2$。
\end{proof}

\begin{proof}[定理~\ref{thm:fisher} 的证明]
记 $\mu = R$。对数似然的偏导为
$\partial_\mu \log p = \frac{k(x-\mu)}{\mu(k+\mu)}$，
$\partial_k \log p = \psi(x+k) - \psi(k) + \log\frac{k}{k+\mu} + \frac{\mu}{k+\mu}$，
其中 $\psi$ 为 digamma 函数。由 $\mathbb{E}[X] = \mu$ 与得分恒等式 $\mathbb{E}[\partial_k\log p] = 0$，
\begin{align*}
I_{\mu k} &= \mathbb{E}\bigl[\partial_\mu \log p \cdot \partial_k \log p\bigr]
= \frac{k}{\mu(k+\mu)}\,\mathbb{E}\bigl[(X-\mu)\,\partial_k \log p\bigr]
= \frac{k}{\mu(k+\mu)}\,\operatorname{Cov}\bigl(X, \partial_k \log p\bigr)\\
&= \frac{k}{\mu(k+\mu)}\,\partial_k \mathbb{E}[X] = 0,
\end{align*}
因为负二项的均值 $\mu$ 不依赖 $k$。又
$I_{\mu\mu} = \mathbb{E}[(\partial_\mu\log p)^2] = \frac{k^2\operatorname{Var}(X)}{\mu^2(k+\mu)^2} = \frac{k^2(\mu + \mu^2/k)}{\mu^2(k+\mu)^2} = \frac{k}{\mu(k+\mu)}$。
信息阵对角，故联合估计下 $\operatorname{Var}(\hat R) \ge 1/(N I_{\mu\mu}) = R(R+k)/(Nk)$，与 $k$ 已知时一致。相对标准误 $\sqrt{R(R+k)/(Nk)}/R \le \varepsilon$ 等价于 $N \ge (1 + R/k)\varepsilon^{-2}$。\end{proof}

\begin{proof}[定理~\ref{thm:horizon} 的证明]
(i) 单调性。由注~\ref{rem:approx_accuracy} 前的分解，$\text{CV}^2_{\text{macro}}(h) = \frac{R}{I_0(q-R)}\bigl[(1+1/k_{\text{agg}})^h - R^{-h}\bigr] + \bigl[(1+1/k_{\text{agg}})^h - 1\bigr]$。在 $R>1$、$q>R$ 时两处括号均关于 $h$ 严格递增（$(1+1/k)^h$ 递增而 $R^{-h}$ 递减）；$P_{\text{exact}}(h) = e^{2x}-2e^{x/2}+1$（$x = h^2 s^2$）关于 $x$ 的导数 $2e^{2x} - e^{x/2} > 0$，故严格递增。于是 $\text{RelMSE}$ 连续、严格递增，$\text{RelMSE}(0)=0<\tau^2$ 且 $h\to\infty$ 时发散，唯一根存在。（ii）$h^*$ 对 $s$ 的单调性由隐函数求导 $\mathrm{d}h^*/\mathrm{d}s = -(\partial\,\text{RelMSE}/\partial s)/(\partial\,\text{RelMSE}/\partial h) < 0$ 给出。（iii）线性化：在阈值方程 $\text{RelMSE}(h)=\tau^2$ 中以 $[(1+1/k_{\text{agg}})^h-1] \approx h/k_{\text{agg}}$ 近似几何项、略去亚主导项并以 $P_{\text{quad}}$ 代替 $P_{\text{exact}}$，得 $s_{\text{周}}^2 h^2 + h/k_{\text{agg}} = \tau^2$，其正根即式~\eqref{eq:h_star_closed}。近似精度的量化见注~\ref{rem:approx_accuracy}。
\end{proof}
