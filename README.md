## 📌 Executive Summary (研究核心结论)

Adapting the ecological forecast horizon paradigm (Petchey et al., 2015) to branching-process epidemic dynamics, this study derives an additive decomposition of prospective relative mean squared error under assumptions (A1)–(A4):

$$\text{relMSE}^2(h) = \underbrace{\text{CV}^2(h)}_{\text{Demographic Stochastic Floor}} + \underbrace{P(h)}_{\text{Parameter Amplification}} \le \tau^2$$

Key findings (all numbers generated by the v2 chain below):

1. **Macro scaling vs. micro floor.** In national aggregate surveillance the Law of Large Numbers smooths demographic stochasticity (≤ 0.74% of τ² = 0.25); horizons are governed by the inference signal-to-noise and the generation interval. In micro outbreaks (I0 ≤ 200), the intrinsic floor binds.
2. **Empirical horizons.** Non-RSV early-growth phases: 7.9–21.2 weeks (exact roots, parametric-bootstrap CIs; Delta 21.2 [11.6–80.1]). RSV seasons yield uncapped mathematical extrapolation roots (41.5 / 67.8 weeks) that exceed the 16–20-week single-season span; RSV 2025–26 additionally falls below the Cramér–Rao required independent-cluster count (ratio 2.46).
3. **Four-term error accounting.** Modeled mechanistic terms explain 0.4%–48.4% of the observed relative MSE across 12 rolling configurations; unmodeled structural residuals account for 51.2%–99.6%.
4. **Two-tier, exploratory framework.** Rolling out-of-sample crossings vs. a persistence baseline are 1.8–5.3 weeks (moving-block bootstrap 95% CIs), below the corresponding theoretical horizons in point estimate; the envelope reading is exploratory given the sample size.

## 🔁 One-command replication

```bash
python scripts_v2/make_all.py          # full chain, ~5–7 min
python scripts_v2/make_all.py --fast   # skip theorem simulations, ~3 min
```

The chain: parameter estimation + parametric bootstrap → rolling evaluation →
four-term error accounting → theorem/Corollary verification → figures → LaTeX
table bodies → consistency tests (build fails on any manuscript/JSON divergence).

Input data files are hash-pinned in [`MANIFEST.md`](MANIFEST.md) together with
per-stage runtimes and provenance notes. See that file for the step table.

## 🧪 Environment

Python 3.11 with numpy, scipy, pandas, matplotlib, lightgbm, torch (see
`environment.yml`). LaTeX: tectonic or any XeLaTeX with CJK fonts
(`paper_cn_journal_template/main.tex` compiles with `tectonic -X compile main.tex`).

All stochastic steps are seeded (20260807): bootstrap (B = 2000), rolling
moving-block bootstrap (1000 resamples), and the theorem simulations.
