All numerical results in the manuscript are generated by a single build chain.

Provenance of the processed inputs: national-level weekly aggregates of the CDC
datasets named in the manuscript's Data Availability statement (COVID Data
Tracker `pwn4-m3yp`; NHSN hospital admissions for JN.1; FluView ICL clinical
labs; NREVSS `rgnm-fkqb`), snapshot March 2026 archive. Raw snapshots for the
RSV NAAT-positivity dataset and the COVID weekly-cases dataset retrieved
2026-09-07 are archived under `data/raw/` for reference; the RSV positive-count
series in the processed file corresponds to the March-2026 vintage and is not
byte-identical to the live-API values (later backfill), hence the processed
files themselves are the frozen analytical inputs and are hash-pinned here.

## Build chain (`scripts_v2/`)

| Step | Script | Outputs |
|---|---|---|
| 1 | `pipeline.py` | `reports/table2_params.json` (params, exact roots, bootstrap CIs; B=2000, seed 20260807) |
| 2 | `rolling_eval_v2.py` | `reports/rolling_results.json`, `reports/figures_v2/fig7_skill_decay.png` |
| 3 | `error_budget_v2.py` | `reports/table4_budget.json`, `reports/figures_v2/fig6_error_budget.png` |
| 4 | `verify_suite.py` | `reports/verify_t5R_v2.json`, `reports/verify_t5R_renewal_v2.json`, `reports/corollary1_grid.json` |
| 5 | `make_all_figures_v2.py` | `reports/figures_v2/*.png` (single canonical figure directory) |
| 6 | `make_tables_v2.py` | `reports/table_bodies.tex` (LaTeX table rows) |
| 7 | `check_consistency.py` | pass/fail assertions vs. manuscript claims (build fails on divergence) |
| 8 | LaTeX compile | `paper_cn_journal_template/main.pdf` (tectonic or any XeLaTeX) |

One command: `python scripts_v2/make_all.py`  (add `--fast` to skip step 4).

Also generated: `reports/crb_analysis.json` (Cramér–Rao required-cluster
analysis for Section 4.1) via `pipeline.crb_analysis`.

## Runtime (8-core desktop CPU, 16 GB RAM)

- `pipeline.py` ≈ 1–2 min (bootstrap dominates)
- `rolling_eval_v2.py` < 30 s
- `error_budget_v2.py` < 30 s
- `verify_suite.py` ≈ 3 min
- figures + tables < 1 min

## Consistency guarantees

`check_consistency.py` asserts: every referenced figure exists in the canonical
directory and has no divergent copies elsewhere in the repo (excluding
`_archive/`); Table 2 parameter rows in the generated bodies match the JSON;
the abstract's headline horizon range matches the JSON extremes; Table 5
crossings match the rolling JSON; the CRB prose claims match
`crb_analysis.json`; known-stale literals from previous versions are absent.

## Legacy material

Pre-v2 scripts are kept unmodified under `scripts/legacy/` for the record; they
are NOT part of the build chain. Superseded report JSONs and duplicate figure
directories are archived under `_archive/`.
