# 《传染病传播动力学的可预测视界、理论极限与实证研究》同行评审意见

## 1. 摘要式总结（Summary）

本文研究传染病传播预测在临界区附近的可预测时间边界。作者以负二项 Galton–Watson 分支过程为微观生成模型，将预测相对均方误差分解为内在传播随机性与传播参数估计误差，并据此给出超临界及近临界条件下预测视界的解析近似。论文进一步讨论有限种群中的拟平稳扩散、建群概率、基于 Fisher 信息的样本量界，以及时变和 AR(1) 传播扰动下的方差累积。作者通过多组蒙特卡洛模拟、MLP 与 LightGBM 基准，以及美国 COVID-19、流感和 RSV 周监测数据进行检验；报告的精确理论视界约为 4.7–49.4 周，而五项误差预算中未解释残差占 63.2%–86.0%。论文据此提出理论视界与现实操作视界的双层解释框架。

## 2. 优点（Strengths）

1. **核心问题被明确地算子化。** §2.3 的定理 1、式（15）–（20）不是停留在“疫情难以预测”的定性判断，而是把容忍度 τ 与 R、k、I₀、δR 联系到可计算的视界；表 2（P16）又同时报告一阶近似根与精确数值根，使近似误差能够被检查。
2. **理论推导链条完整且适用条件大多显式。** §2.2–§2.7（P4–P12）依次给出引理 1–3、定理 1–5R 和推论 1–3的证明。尤其是定理 1 明确以假定 A4 保证交叉项归零，定理 2 明确要求 R̂ 的支撑非负且方差非退化，式（16）也承认 hδR/R ≪ 1 的局部适用域。
3. **作者没有掩盖闭式近似的系统偏差。** §2.3（P8）和表 2（P16）并列展示 h*approx 与 h*exact，并说明凸性带来的参数误差低估和有限步内在方差地板的反向偏差。七个阶段中闭式近似相对精确根偏高约 11%–16%，这一数量级与表中数值一致。
4. **模拟覆盖了多个理论模块。** 表 1（P12）不仅检验核心 CV² 与正交分解，还涉及拟平稳分布、建群概率、Cramér–Rao 界及 AR(1) 漂移；图 2–图 4（P13–P14）的题注报告了理论值与经验值的比值，便于读者判断近似紧致程度，而非只给视觉曲线。
5. **论文主动区分理论误差界与现实模型误配。** §4.2 的式（36）、表 3及图 6（P15–P17）把内在随机性、漂移、参数误差、交叉项和未解释残差并列呈现。尽管该分解目前尚不可复现，但它避免了把全部现实误差归因于不可约随机性的概念混淆。

## 3. 缺点（Weaknesses）

**致命：**基于当前可核实材料，未发现足以证明核心数学框架整体不成立、且无法通过重分析或补充实验修复的致命问题。以下问题按严重程度排序。

1. **重大：核心理论的独立性假定与实证分解不相容。** 定理 1（§2.3，P7–P8）依赖 A4，并据此声称参数误差与微观随机误差严格正交；但表 3（P17）七行的 E_cross 均非零，为 −0.2% 至 −2.0%，作者还将其解释为滑动窗口估计量与后续波动的经验相关。这表明 A4 在本文实证设置中并不成立。影响范围涵盖“严格正交分解”、由该分解导出的现实视界解释，以及摘要中的核心贡献表述。
2. **重大：实证部分没有检验理论视界是否对应真实预测技能的失效点。** 表 2（P16）只是将同一数据窗口估计出的参数代入式（16）或数值求根，未进行滚动 forecast origin 的样本外预测，也未报告 WIS、覆盖率、偏差或相对基线技能。因而目前证据支持“计算出理论量”，但不支持 §4.2–§5.1 所称现实操作视界为 1–4 周，亦不足以证明该界能改善公共卫生预测决策。影响范围是论文的主要实证主张，而非理论推导本身。
3. **重大：近临界结论恰在最关键参数区间缺少清晰验证。** 定理 3（§2.5，P9–P10）主张 |ε| 为 O(N⁻¹ᐟ²) 的临界窗口；N=2000 时对应量级约为 0.022。图 3（P14）题注却只标出 ε=0.2 与 0.4，两者均远离该窗口。表 1虽列 ε=0.005、0.01，但 §3.2 未把近临界比值 0.976、0.950 对应到具体参数、样本量和误差定义。影响范围是“临界慢化和拟平稳动力学得到模拟验证”的主张。
4. **重大：误差预算和参数估计过程不足以复现。** §2.1（P4）未给 CDC 数据访问日期、版本、URL 和七个阶段的起止周；§4.2（P15–P17）未说明 E_drift、P、E_cross、E_misspec 的实际估计算法，表 3也无不确定性区间。RSV 两行 k_agg 恰为 1000.0（表 2），疑似触及估计上界，但论文未说明边界约束或 k 的不确定性。影响范围包括 63.2%–86.0% 残差占比、RSV 的长视界以及跨病原体比较。
5. **重大：新颖性与机器学习结论均超出当前比较范围。** §0、§1.2 将结果表述为此前未有的闭式视界，但“阈值定义预测视界”、负二项传播异质性下 R 的不确定性、SIS 临界标度等构件均有直接先行工作 [1]–[5]；本次检索虽未发现完全同型的五参数 h*，却不足以支持排他性断言。§3.3（P13–P15）仅用单一种子、单一 MLP 和 LightGBM 与 MLE 比较，MLP 方差比 6.69 只能说明该实现没有胜过 MLE，不能证明机器学习一般受到该界的紧约束。影响范围是贡献定位和摘要中的广义算法结论。
6. **次要：正文存在多处可核查的数值与口径不一致。** §2.1（P4）称 Bootstrap 5,000 次，而表 2注（P16）称 2,000 次；图 1（P5）的视界公式缺少式（16）中的除以 7 周换算因子；§4.2 的“5–58 周”、§5.1 的“5–18 周”和表 2实际 4.7–49.4 周不一致；定理 4所谓按零假设边界保守评估，实际却代入 R=1.1 得到 231 与 1,428，而 R=1 时相应约为 200 与 1,237。影响范围主要是结果解释、量纲和读者信任，不必然推翻基础公式。
7. **次要：投稿元信息、引用和呈现尚未达到可发表状态。** 首页（P1）没有作者、机构或通讯信息，全文没有数据代码可得性、利益冲突、基金或致谢声明；表 1（P12）的参数与轨迹数对应关系拥挤且有歧义；抽查发现参考文献 [9]、[32]、[37]、[38] 存在题名或 DOI 实质错误，其中 [37]、[38] 又是定理 3的重要依据。影响主要是可追溯性、复现性和出版规范。

## 4. 详细意见（Detailed Comments）

### 4.1 方法与理论正确性

1. **重新界定定理 1与实证模型的关系。** 建议作者在定理后明确区分理想模型下的严格分解与数据驱动估计下的一般分解。若 R̂ 与预测期随机实现相关，应保留协方差项并给出其符号或上界，而不是一面称其严格为零、一面在表 3估计非零 E_cross。至少应补充一项模拟：让估计窗口与预测窗口按实证流程相邻，逐步增加序列自相关，展示 A4 失效时 h* 的偏差。
2. **澄清 relMSE² 的记号。** 式（15）将名为 relMSE² 的量写成相对均方误差之和，而容忍度用 τ²；这容易让读者误以为 MSE 被再次平方。建议统一为 relative MSE 或 squared relative RMSE，并在首次定义时给出量纲。
3. **修正定理 4的检验口径。** §2.6 应明确 Fisher 信息是在备择值 R=1.1 还是零假设边界 R=1 处计算。若 231 与 1,428 保留，应删除“按零假设边界保守评估”或给出为何在 R=1.1 计算仍保守的证明；若坚持零假设口径，则应相应改为约 200 与 1,237，并同步修改摘要、图 1和 §5.1。
4. **限制 Cramér–Rao 结论的对象。** 定理 4陈述的是渐近无偏估计量，§3.3 却扩展到“任何无偏估计器”，且讨论神经网络时未控制偏差。建议同时报告 bias²、variance 与 MSE，并明确经典 CR 界并不直接约束一般有偏估计器；如要覆盖后者，应使用相应的有偏 CR 界或局部极小极大界。
5. **补足定理 3的边界条件与贡献边界。** 零概率通量解 π(x) 含 x⁻¹ 因子，作者应说明零点吸收、准平稳条件化、归一化区间及所用正则化如何共同保证这是可用密度。还应逐项区分本文结果与 Nåsell、Dolgoarshinnykh–Lalley、Kessler 及 O'Regan–Drake 的已知临界标度 [3]–[5]，避免把已有的 N⁻¹ᐟ² 窗口和 N¹ᐟ² 时标作为未加限定的新定理。
6. **说明式（16）的存在条件与无解情形。** 根号项要求 τ² 大于内在随机性地板。建议将“无正实数视界”作为正式分支列出，并解释 h=0 或 h=1 的离散代际定义；这对于 I₀ 小、k 小的微观暴发尤为重要。
7. **修正时变传播部分的贡献措辞。** 定理 5R 的平稳 AR(1) 累计和方差及单位根下 h³ 量级是标准时间序列结果。建议将贡献表述为“把标准累计方差律嵌入本文传播视界框架”，并说明 η_t、r_t、过程噪声与观测噪声之间的条件独立关系，而非把代数结果本身作为主要新定理。

### 4.2 实验设计与证据强度

1. **增加真正的样本外预测验证。** 对 CDC 三类病原体，建议设置逐周滚动 forecast origin，只使用当周可见数据估计 R、k 和 δR；预测未来 1–H 周并报告 WIS、区间覆盖率、sharpness、bias 及 relative WIS。随后检验技能越过预设阈值的经验 horizon 是否与 h* 对齐。Forecast Hub 的滚动评估与 WIS 协议可作为直接模板 [6][7]。
2. **为“1–4 周操作视界”提供可计算来源。** 目前表 3只给各误差项占比，并不能推出操作视界。建议预先定义操作阈值，例如 relative WIS 不优于 persistence baseline、预测区间覆盖失真或 relRMSE 超过 0.5，再从滚动实验中估计跨越周数及 Bootstrap CI；若无法补做，应删除 1–4 周这一具体数字。
3. **把近临界参数组完整呈现。** 建议在图 3或新表中分别报告 ε=0.005、0.01、0.2、0.4 的 N、轨迹数、burn-in、采样长度、正则化常数、理论与经验 CV、密度距离及其 Monte Carlo 区间。尤其需指出 0.976、0.950 分别对应哪组参数，并解释 8 格建群概率中哪一格未进入 95% 区间。
4. **正确解释 CR 比值低于 1的现象。** 图 4（P14）报告最低 0.57，而 CR 下界在其正则条件和同一无偏估计问题下不应被系统穿透。作者提出的条件收缩解释意味着比较对象已变成按累计病例分箱后的条件分布。建议在无条件固定样本设计中重做验证，并将条件分箱结果另列；同时报告估计偏差和覆盖率。
5. **扩展机器学习与领域基线。** 至少应加入 persistence/flat baseline、一个标准 R_t 工具（EpiEstim、EpiFilter 或 EpiNow2）以及一个概率预测模型；对每个模型使用多个随机种子和相同数据切分，报告均值、标准差及配对区间。若只保留当前合成实验，结论应缩窄为“在本研究指定架构与正确设定的 NB 合成数据上未观察到优势”。
6. **兑现代间隔敏感性承诺。** 引言（P2）承诺检验 μg 变化，但 §4只检验 W 为 4、6、8周。由于周视界与 μg 线性相关，建议对每种病原体使用文献支持的代间隔分布或至少低、中、高三档，联合传播其不确定性到表 2的 CI。
7. **解释病例阶段选择。** 对七个“典型阶段”给出预先定义的纳入标准、具体起止周和排除对象；最好以全部满足规则的季次替代人工挑选。否则无法排除选择性报告，尤其是 RSV 两季产生最长视界的情况下。

### 4.3 与已有工作的关系与新颖性

1. **将新颖性从排他性声明改为可证实的窄声明。** 建议把“此前尚未有研究”改为“据作者所知，本文首次在统一的负二项分支框架中将 R、k、I₀、δR 与 τ 组合为显式 h*”。本次有限范围检索未发现完全同型公式，但不能证明不存在；这一限定既准确，也不会削弱统一框架的价值。
2. **补引最直接的先行工作。** §0与 §2.3 应补充预测视界的阈值定义与闭式求解先例 [1]；§1.4与 §2.6 应补充超扩散条件下 R 不确定性的同型结果 [2]；§1.3与 §2.5 应补充 SIS 准平稳分布与临界慢化的基础工作 [3]–[5]。
3. **准确描述与 Parag 和 Donnelly 的差异。** 论文对参考文献 [43] 的定位基本合理：该工作使用 Poisson 更新过程推导 R 的 Fisher 信息，没有 k 和 h* [8]。建议保留这一对照，同时加入 Johnson 等在 R≈1 时得到约 1/(kC) 不确定性量级的结果 [2]，从而说明本文增量主要是判别门槛和统一视界表达，而不是首次把 k 引入 R 的信息限制。
4. **补充理论可预测性与实测技能的连接工作。** White 和 León 已将时间序列 forecastability 与 Hub 的 0–4周 MAE、WIS 和相对技能做经验对照 [7]。该文应在 §1.1与 §4讨论，并可直接帮助作者设计缺失的样本外闭环。
5. **降低“算法无法突破理论界”的概括强度。** 正确似然下的 MLE 接近 CR 界，并不意味着任意预测任务、任意损失函数或模型误配下的 ML 都由同一标量界紧约束。应把参数估计的局部信息界与完整概率预测的可达技能分开讨论。

### 4.4 可复现性

1. 增加数据与代码可得性声明，给出仓库永久链接、许可证、环境文件、软件版本、硬件和运行时间。代码至少应覆盖表 1–表 3、图 2–图 6及全部随机模拟。
2. 对三个 CDC 数据源给出直接 URL、访问日期、下载时间戳或快照哈希、变量名、修订处理规则，以及七个阶段的准确起止周。CDC 序列会回溯修订，仅写产品名称无法精确复现。
3. 统一 Bootstrap 次数，并给出重采样单位、参数化分布、区间类型及随机种子。模拟部分也需给出可复用种子或种子生成规则；ML 的种子 42不足以替代多次重复。
4. 详细写出表 3每一项的估计算法、归一化分母和负交叉项处理方式，并为每个百分比提供 Bootstrap 区间。E_misspec 作为剩余项会吸收前四项的所有估计误差，不能在没有不确定性的情况下作因果解释。
5. 报告 k_agg 的估计约束、搜索上限和置信区间。若 1000.0 是边界截断，应直接标注“≥1000”并以 α=1/k 做稳健性分析；已有研究指出矩估计在接近泊松极限或小样本时可能不稳定 [9]。
6. 提供每项实验的最小复现实例与机器可读结果表，避免读者只能从位图读取比值。表 1应拆成一行一个参数组合，消除当前的行归属歧义。

### 4.5 写作与呈现

1. 摘要（P1）约 700字且逐条堆叠多个定理。建议压缩为研究问题、方法、两个最重要结果和适用边界，并把“全面验证”“坚实基准”等强评价替换为可核查数值。
2. 统一 h*、h*gen、h*周、h*approx、h*exact 的含义和单位。建议用 h 表示代数、T 表示日或周，并在所有图表列头写单位；图 1公式应补上除以 7，或明确结果单位为天。
3. 统一视界范围。表 2精确根为 4.7–49.4周；若 §4.2 的 5–58周来自近似根、Bootstrap 上限或其他口径，应明确说明，不能与 §5.1 的 5–18周混用。
4. 对图 2–图 4，建议除理论/经验比值外提供误差条、参数编码和有限样本偏差；对图 6，应在题注声明 E_misspec 是代数残差而非独立识别的机制。
5. 将局限性从一般性声明改成与结论逐项对应：A4 失效限制定理 1的实证适用，模型误配限制 CR/ML 外推，无样本外评测限制“操作视界”结论，阶段选择限制跨病原体概括。

### 5.2 评分

**5/10**

论文提出了一个清晰、有潜在实用价值的统一解析框架，核心分支过程矩推导、误差单调性和闭式视界计算在所述理想假定下具有较好的完整性，且表 2允许核查近似偏差。然而，当前稿件的主要经验结论尚未形成样本外预测闭环；A4 与表 3的非零交叉项存在直接张力；近临界验证、误差预算复现、新颖性定位和引用准确性也都需要实质补强。这些问题影响的是论文的核心论证链，而非仅靠文字润色即可解决，因此不宜 Minor Revision，也尚不足以直接接收。现有问题尚未显示基础理论必然错误，故不建议 Reject。
